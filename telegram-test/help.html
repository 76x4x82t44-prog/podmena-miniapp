Как работает сервис

  1. Откройте Mini App из бота ПОДМЕНЫ в Telegram и заполните анкету для нужной роли.
  2. Сотрудник выбирает смену и откликается. Руководитель создаёт смену и выбирает исполнителя из откликов.
  3. Стороны могут общаться по смене в приватном чате. Подтверждение выполнения и спор открываются через карточку смены.
  4. После окончания смены руководитель запрашивает подтверждение. После подтверждения обеими сторонами доступны история и отзывы.

Каталог показывает анкеты сотрудников, которые включили видимость в профиле. Для общения через каталог сначала нужен принятый запрос на связь.

В карточке может отображаться согласованная сумма. Выплату стороны проверяют отдельно.

Поддержка

Если не работает вход, полностью закройте Mini App и снова запустите её из Telegram. При проблеме сохраните время и название экрана без данных анкеты или переписки.

Для жалобы на пользователя используйте действие Пожаловаться в чате. Блокировка закрывает дальнейшую отправку сообщений. Для разногласий по выполнению смены откройте спор в карточке смены.

Для обращения к организатору используйте канал связи, указанный при приглашении в пилот. Передавайте только сведения, необходимые для разбора вопроса.

Чтобы снова войти, откройте бота и запустите Mini App его кнопкой. Открыть @podmenaspb1_bot

Политика конфиденциальности

Черновик для юридической проверки. Владелец пилота должен уточнить сведения об операторе, контакты для обращений, сроки хранения и порядок удаления данных перед публикацией итоговой политики.

Какие данные нужны сервису

Сервис использует данные входа Telegram для проверки аккаунта. Хранит анкеты, сведения о сменах, отклики и назначения, отзывы, переписку, записи споров и настройки видимости и уведомлений.

Кому видны данные

Анкета сотрудника появляется в каталоге после включения видимости. Разрешённые поля анкеты видны руководителям. Телефон и закрытые контакты в каталоге не отображаются. Отключение видимости убирает анкету из каталога. Это не удаляет смены, уже созданные связи или переписку.

Историю приватного чата видят его участники. Жалоба передаётся на разбор организатору. Ход спора доступен участникам смены. Уведомление в Telegram сообщает о событии без текста переписки и причины спора.

Управление настройками

В профиле можно выключить видимость анкеты и Telegram-уведомления. За разъяснениями о данных, исправлении или удалении обратитесь к организатору пилота по его объявленному каналу.

Правила пользования

Черновик для юридической проверки. Перед пилотом организатор должен утвердить условия участия, канал поддержки и порядок обработки жалоб.

Используйте свой аккаунт Telegram, заполняйте анкету достоверно и заранее согласовывайте условия смены. Указывайте только сведения, на публикацию которых у вас есть право.

Используйте запросы связи по рабочим вопросам. Запрещены массовые рассылки, угрозы, оскорбления и публикация чужих персональных данных. О нежелательном контакте можно сообщить через чат.

ПОДМЕНА помогает согласовать смену. Приложение не принимает и не переводит деньги. Подтверждение выполнения не подтверждает выплату. Названия площадок обозначают тип ПВЗ.
