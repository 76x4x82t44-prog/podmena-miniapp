# Интерфейс ПОДМЕНЫ для пилота

## Макеты для Figma

Используйте ширины 360, 390 и 430 px. Набор ниже можно перенести в переменные Figma и собрать как компонентную спецификацию. Реализация остаётся в существующем HTML и `telegram-test/pilot.css`.

| Токен | Значение | Применение |
| --- | --- | --- |
| `--pilot-deep` | `#10251E` | Шапка приложения, фон счётчика чатов |
| `--bg` | `#F4F7F5` | Фон страницы |
| `--card` | `#FFFFFF` | Карточки и поля |
| `--ink` | `#17251E` | Основной текст |
| `--muted` | `#4F6358` | Вторичный текст и неактивные вкладки |
| `--green` | `#087B51` | Основные действия с белым текстом |
| `--green2` | `#E4F2E9` | Активные вкладки, метки, исходящие сообщения |
| `--line` | `#DDE7E0` | Разделители и границы карточек |
| `--pilot-line-control` | `#85978C` | Граница поля |
| `--pilot-focus` | `#285F93` | Обводка фокуса |
| `--pilot-danger` | `#8E251E` | Текст ошибки |
| `--amber` | `#FFF4D9` | Информационное предупреждение |
| `--pilot-radius` | `16px` | Радиус карточки |
| `--pilot-touch` | `44px` | Минимальная высота обычного действия и ссылки справки |
| `--pilot-tab-space` | `72px + safe-area-inset-bottom` | Резерв под нижнюю панель |

Основной шрифт системный, текст 15 px с межстрочным интервалом 1,5. Поля и элементы выбора имеют размер шрифта 16 px. Заголовки карточек начинаются с 16 px. Окончательный размер контейнера Mini App ограничен 520 px.

## Компоненты и состояния для сборки

| Компонент | Варианты и поведение |
| --- | --- |
| Нижние вкладки | Главная, Поиск, Смены, Чаты, Профиль. Активная вкладка получает светлую подложку, у Чатов появляется счётчик |
| Навигация роли | Ищу смену / Ищу замену. Доступ к операциям зависит от серверных прав |
| Карточка смены | Площадка, адрес, дата и время, согласованная сумма, текстовый статус, доступные действия |
| Карточка сотрудника | Разрешённые поля, подтверждённые смены и рейтинг. Состояния запроса связи зависят от сервера |
| Список диалогов | Участник, непрочитанное, состояние связи. Переписка и спор находятся в разных разделах |
| Сообщение | Входящее на белом фоне, исходящее на светло-зелёном. Длинный текст переносится внутри карточки |
| Форма | Подписи полей, ожидающее действие, недоступное действие и отдельный текст ошибки |
| Настройки | Видимость анкеты и уведомления, каждое действие с подтверждением состояния |
| Диалог | Заголовок, объяснение, основное и вторичное действие, обратная связь по ошибке |
| Справка | Разделы работы сервиса, поддержки, приватности и правил. Юридические разделы помечены как черновики |

Статус всегда читается как текст. Цвет и оттенок служат дополнительными признаками. Фокус отображается контуром 3 px. Небольшие элементы выбора обёрнуты в подпись размером для касания. Комбинации клавиатуры, системных панелей и горизонтальной ориентации нужно проверить в Telegram WebView на iOS и Android.

## Правила раскладки

- Оставляйте 16 px по краям основного экрана. До ширины 380 px допустим отступ 12 px.
- На узком экране поля фильтров и действия переносятся на следующую строку. Длинные адреса, отзывы, сообщения и ошибки переносятся внутри контейнера.
- Резервируйте safe areas под шапку и нижнюю навигацию. Диалог должен прокручиваться внутри окна при маленькой высоте.
- Используйте состояния, соответствующие данным. При нулевом результате показывайте пустое состояние, при сетевой ошибке — повтор или явную недоступность.
- В Figma используйте вымышленные имена, адреса и сообщения. Данные участников пилота в макетах не нужны.
